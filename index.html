How the calculator works

Basic formula

Basic mode is intended for a quick first estimate. The default DB size of 5 GB and filestore size of 10 GB are only starting estimates and should be replaced when better project data is available.

Concurrent Users = Total Users × Concurrency % Effective Concurrent Load = Concurrent Users × Workload Factor HTTP Workers = ceil(Effective Concurrent Load / 6) Worker Equivalent = HTTP Workers + 1 Cron Worker Minimum CPU ≈ (Worker Equivalent - 1) / 2 Recommended CPU = Minimum CPU × 1.30 Odoo worker RAM ≈ Worker Equivalent × 325 MB Combined-server RAM also reserves memory for PostgreSQL, the OS, and cache, adds 15% headroom, then rounds up to a server tier.

Advanced formula

Effective Concurrent Load (ECL) = Concurrent Users × Workload Factor × Transaction Factor × Customization Factor HTTP Workers = ceil(ECL / Users Per Worker) Worker Equivalent = HTTP Workers + Cron Workers + Queue Worker Equivalent

Rough transaction-to-DB estimate

This helper is intentionally simple and does not replace the database-size input. It only gives a rough monthly growth reference from estimated business transactions.

Base Transaction Footprint ≈ 20 KB / business transaction Rough Monthly DB Growth = Transactions / Month × 20 KB × Workload Factor × 1.35 DB/Index Overhead

The 20 KB baseline is a calculator assumption, not an official Odoo value. Real storage can be lower or significantly higher depending on document lines, journal entries, stock moves, chatter, custom fields, indexes, automation, and installed modules. Attachments belong mainly to the filestore and are not included in this rough estimate.

Separate PostgreSQL Server

When enabled, the calculator splits the recommendation into an Odoo application server and a PostgreSQL server. The Odoo side is sized mainly from workers, CPU, and Python memory. The PostgreSQL side is sized separately with more emphasis on RAM and database storage.

Odoo App Server RAM = Odoo Worker RAM + OS / Services + App Cache + Headroom PostgreSQL Server RAM = DB-size preset stepped up by effective concurrent load shared_buffers starting point ≈ PostgreSQL Server RAM × 25%

The PostgreSQL sizing preset starts at 4 GB RAM and 2 vCPU for a database up to 20 GB with low effective concurrent load. It is a calculator heuristic, not an official PostgreSQL formula. For existing systems, measured working set, cache hit ratio, query concurrency, connection count, and storage IOPS should take priority. Keep both servers on a low-latency private network.

Important notes

This calculator is a capacity-planning aid, not an official Odoo benchmark. For an existing system, measured peak CPU, worker RSS, PostgreSQL usage, slow queries, queue load, transaction volume, database growth, and filestore growth should replace generic assumptions wherever possible.
